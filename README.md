# Phone UI

Simple messenger UI built with Unity UGUI.

## About

A small Unity project featuring a messenger-style interface.

Includes message sending, chat history, simulated incoming messages, custom keyboard input handling, chat scrolling, and dynamically sized message bubbles.

## Features

* Messenger UI
* Dynamic message bubbles
* Left / right message alignment
* Message timestamps
* Simulated friend messages
* Custom keyboard input
* Mouse wheel scrolling
* Status bar clock

## Tech

* Unity 6
* C#
* UGUI
* Unity Input System
* [UniText](https://github.com/LightSideKittens/UniText)
